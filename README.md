## Overview

LM Studio is a polished desktop application for discovering, downloading, and running local language models on Windows, macOS, and Linux. It features a native ChatGPT-like chat interface, a model discovery browser searching Hugging Face, a local inference server with an OpenAI-compatible API, and multi-model session comparison.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **LM Studio** delivers the features you need in a clean, intuitive package.

> Official website: [lmstudio.ai](https://lmstudio.ai)

## Key Features

| Feature | Description |
|---------|-------------|
| **Model Browser** | In-app Hugging Face browser for discovering and downloading models |
| **Chat Interface** | Polished native chat UI with conversation history management |
| **Local Server** | OpenAI-compatible local API server for developer integrations |
| **Multi-Model** | Load and compare outputs from two models side by side |
